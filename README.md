# ThatDataPurple.Firefox
A purple theme for Firefox and Thunderbird in the That Data Person brand colours, by That Data Person Limited.

![Screenshot of ThatDataPurple theme applied to Firefox](https://github.com/thatdataperson/ThatDataPurple.Firefox/blob/main/images/ThatDataPurple.preview.png?raw=true)

![Screenshot of ThatDataPurple theme applied to Thunderbird](https://github.com/thatdataperson/ThatDataPurple.Firefox/blob/main/thunderbird/images/ThatDataPurple.preview.png?raw=true)

## 2026 refresh
The theme now follows the That Data Person branding: a deep brand-dark (`#0D0629`) window frame and background tabs, a brand purple (`#4320CC`) toolbar and selected tab with white text, and a dark address bar with a light purple (`#B9A8FF`) outline. Menus and built-in pages switch to dark; websites keep following your system setting.

Thunderbird gets the same colours, plus dark folder, message list and reading panes.

Tab, toolbar, address bar, menu and sidebar text all meet WCAG 2.2 AA (at least 4.5:1). The colours are generated from the shared palette in [ThatDataPurple](https://github.com/thatdataperson/ThatDataPurple/tree/main/palette); see its contrast report for the numbers.

## Supported Versions
- Firefox 106+
- Thunderbird 128+

## Install
### Firefox
[ThatDataPurple](https://addons.mozilla.org/en-US/firefox/addon/thatdatapurple/) is published on Firefox Browser Add-ons.

### Thunderbird
- Download [ThatDataPurple.Thunderbird.xpi](https://github.com/thatdataperson/ThatDataPurple.Firefox/raw/main/bin/Release/ThatDataPurple.Thunderbird.xpi)
- In Thunderbird, open *Add-ons and Themes*, select the gear icon, then *Install Add-on From File...* and choose the file

## Uninstall
[Mozilla](https://support.mozilla.org/en-US/kb/disable-or-remove-add-ons) provide detailed instructions on how to remove add-ons. Thunderbird uses the same *Add-ons and Themes* page.

## Source
`manifest.json` (Firefox) and `thunderbird/manifest.json` are generated by `build/build.py` in [ThatDataPurple](https://github.com/thatdataperson/ThatDataPurple).
